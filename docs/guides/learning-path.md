# 学习路线

建议每个概念经历“**阅读 → 预测 → 实验 → 解释结果 → 回顾**”。

| 阶段 | 章节 | 能力目标 |
| --- | --- | --- |
| 入门与表示 | [01–03](/chapters/01-introduction) | 理解编译执行、补码与浮点数 |
| 机器级与优化 | [04–10](/chapters/04-machine-basics) | 能阅读汇编、分析调用约定与流水线 |
| 内存与系统 | [11–18](/chapters/11-memory-hierarchy) | 理解 Cache、链接与地址翻译 |
| 系统接口 | [19–23](/chapters/19-system-io) | 理解文件描述符、网络接口和线程同步 |
| 综合实践 | [24–28](/chapters/24-classic-labs-i) | 连接多门系统技能并设计可测试小项目 |

## 学习建议

1. 按章节理解核心概念，在代码执行之前先预测结果。
2. 运行 [实验总览](/labs/) 中已有的独立示例。
3. 对示例中的平台相关现象，记录操作系统、编译器和优化选项。
4. 阅读章节后，尝试用自己的语言解释输入、状态变化和输出。
5. 遇到实测性能值，检查原始工作负载与测量方法，避免把示例数据视为普遍规律。

本项目 28 章结构是自主组织的知识路径，并非原版 CS:APP 教材的章节编号。
