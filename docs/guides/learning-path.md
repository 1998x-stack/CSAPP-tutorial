# 学习路线

按知识依赖关系建议分四阶段完成：

| 阶段 | 章节 | 目标 |
| --- | --- | --- |
| 表示与执行 | 01–10 | 数据表示、机器指令、处理器与性能 |
| 内存与链接 | 11–18 | 缓存、链接、异常与虚拟内存 |
| 系统编程 | 19–23 | I/O、网络、进程、线程与同步 |
| 综合实践 | 24–28 | 理解实验目标，并通过自主项目验证 |

每章建议采用“读概念 → 运行最小示例 → 自己解释结果 → 做习题”的循环。涉及测量的结论请记录编译器、系统、CPU、工作负载和命令。

**版本说明：** 本路线是该仓库独立组织的 28 章，不等同于 CSAPP 第三版原书目录。
