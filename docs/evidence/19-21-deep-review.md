# 第 19–21 章第四轮深度推演 · 来源与边界

在 19–23 第二轮基础上，为 19–21 各追加一节 `deep-NNb` 深描、一张内联 SVG（带
`viewBox`/`title`/`desc`/`aria-label`）与纯标准库确定性模型 `examples/deep-ch19-23-b.py`，
回归测试 `tests/content/deep-ch19-23-b.test.mjs`。三节分别处理非阻塞输出游标、
HTTP/1.1 报文定界与 LT/ET 就绪语义。

## 逐章断言与适用范围

- **19b 输出游标**：非阻塞 `write` 可能返回正数、`EAGAIN` 或 `EINTR`；游标只在有正数字节
  传输时前进，已接受前缀不重发、不丢弃，`EAGAIN` 不等于成功。模型以脚本化返回值驱动状态
  机；不模拟内核缓冲、写合成或 TCP 字节流边界。依据 `write(2)`。
- **20b HTTP/1.1 定界**：按 RFC 9112 §6，`Transfer-Encoding: chunked` 优先于
  `Content-Length`，否则读到连接关闭；两者同时出现属错误，不得静默取其一。chunked 解码器
  读十六进制块长、正文、CRLF，直到零长末块。模型不解析真实首部、transfer 参数与完整走私防御。
- **21b LT/ET**：水平触发在条件未清除时反复报告，每次读一块也能推进；边沿触发仅报告一次
  转变，必须在一个事件内读到 `EAGAIN`，否则数据遗留。模型以三个函数断言只有“读到 EAGAIN”
  能在一次事件内取完；不依赖真实内核 epoll 边界行为。依据 `epoll(7)`。

## 不能外推的边界

- 三节均为 POSIX/协议**契约模型**，不是网络分段、内核缓冲或服务器吞吐的实测。
- 19b/20b/21b 的返回值序列是**构造的脚本**，用于验证状态不变量，不代表任何真实内核轨迹。
- 20b 的 chunked 优先级是 RFC 9112 §6 的精简表述；上限检查、慢速攻击预算、TLS/代理差异
  不在本节范围。
- 浏览器验收：以本仓真实 HTTP 服务 + 本地 Chromium 在 1440/390/360px 运行；未执行时记为未验证。

模型命令：`python3 examples/deep-ch19-23-b.py all`（输出 `19b:ok 20b:ok 21b:ok`）。
