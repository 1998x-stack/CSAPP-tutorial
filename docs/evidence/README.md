# 章节来源核查记录

这里统一保存 **01.json—28.json**，与仓库根目录 `01.html`—`28.html` 一一对应。原先散落在根目录 `evidence/` 和 `docs/chapters/*-evidence.json` 的文件已按章号归并，原 JSON 内容保持不变。

这些记录用于记录事实断言、出处、定位信息、适用条件及图解说明，不参与面向读者的静态站点构建。记录内容不是对正文全部事实的自动正确性保证。

## 维护约定

- 文件名统一为两位数章号：如 `01.json`、`17.json`；与 `courses.json` 中的 `num` 对齐。
- 保留各章原有 JSON 结构（有些记录使用 `source_url`，另一些在 `sources` 数组中列明来源），暂不强制改写为另一套模式。
- 每条主张说明技术条件与来源；区分已验证、推导、教学演示和待核实的内容。不要把示意图或模拟结果描述为真实测量。
- 更新、迁移文件时同步维护 `tests/content/`、`scripts/` 和 `.github/workflows/` 中的引用。
