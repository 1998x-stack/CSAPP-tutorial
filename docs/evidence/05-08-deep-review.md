# 第 05–08 章第三轮来源与测试记录

日期：2026-11-26。范围：为 `05.html`–`08.html` 各追加一节 `deep-NNb` 技术深描，
配一张原创图与一个纯标准库确定性模型。目标是给出可复算的状态转换与失效边界，
而非声明任何实机指令选择或性能。

## 逐章断言与来源

| 章 | 新深描主题 | 确定性模型 | 权威来源与边界 |
| --- | --- | --- | --- |
| 05 | 条件传送会无条件求值两路，分支只求值选中一路 | `examples/deep-ch05-08-b.py 05b`：分支在 `p` 为空时返回 0，cmov 模型对空指针也解引用并抛错 | C11 6.5.15p4 只求值一个分支；Intel SDM `CMOVcc`。是否生成 `cmov` 依编译器与优化等级，非 C 语言保证 |
| 06 | 变参函数序言把参数寄存器降入 176 B 保存区，`%al` 给出 SSE 寄存器使用上界 | `06b`：寄存器保存区 = 6×8 + 8×16 = 176 B；第 7 个整数参数溢出到栈；`%al` 上限为 8 | System V AMD64 psABI 寄存器保存区/变参传递。仅限该系统 ABI，Windows x64 不同 |
| 07 | 将下标按无符号重解释，一次比较同时排除负值与上界越界 | `07b`：枚举下标验证与“两个有符号条件”一致；给出 64 位下标截成 32 位的反例 | CERT C ARR30-C；依赖 C 通常算术转换，要求下标与长度宽度一致 |
| 08 | `popq rA` 写回先 `R[%rsp]=valE`、再 `R[rA]=valM`，`rA==%rsp` 时弹出值胜出 | `08b`：`rA=普通寄存器` 与 `rA=%rsp` 两种写回结果 | Y86-64 教学 ISA（CS:APP 3e 第 4 章图目录、SEQ/PIPE HCL）。真实 x86-64 机器编码不同 |

## 不会外推的结论

- 上述数值均为确定性模型的断言结果，不是对某个微架构、编译器版本或优化等级的实测。
- 05 章的“是否使用条件传送”、06 章的寄存器使用、08 章的写回顺序都随 ABI/ISA/实现变化；
  文中已在正文标注“教学示意”或“已作简化”。
- 未做真机指令序列反汇编比对；未声称与任何具体 GCC/Clang 输出逐字节一致。
